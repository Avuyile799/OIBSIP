## Description

This project is a console-based ATM Interface developed in Java as part of the Oasis Infobyte internship.

The application allows users to authenticate with a PIN and perform basic banking transactions.

## Features

- User ID and PIN authentication
- Maximum of 3 incorrect login attempts
- Check account balance
- Withdraw money
- Deposit money
- Transfer money
- View transaction history
- Insufficient funds validation
- Quit the application

## Technologies Used

- Java
- IntelliJ IDEA
- Maven
- Git and GitHub

## Project Structure

- `Account` - stores account information and balance
- `ATM` - handles ATM operations
- `Bank` - manages accounts
- `Transaction` - records transactions
- `Main` - starts the application

## How to Run

1. Open the project in IntelliJ IDEA.
2. Run `Main.java`.
3. Enter the User ID and PIN.
4. Select an option from the ATM menu.
5. Follow the instructions displayed in the console.
