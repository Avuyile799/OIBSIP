
# Java Task 2 - Number Guessing Game

**Author:** Avuyile Twesha

**Task:** Java Task 2 - Number Guessing Game
## Description

This project is a console-based Number Guessing Game developed in Java as part of the Oasis Infobyte internship.

The player has to guess a randomly generated number within a limited number of attempts. The game includes different difficulty levels and keeps track of the player's score.

## Features

- Random number generation
- Easy, Medium and Hard difficulty levels
- Limited number of attempts
- Score calculation
- Option to play another round
- Total score tracking

## Technologies Used

- Java
- IntelliJ IDEA
- Maven
- Git and GitHub

## How to Run

1. Open the project in IntelliJ IDEA.
2. Run `Main.java`.
3. Select a difficulty level.
4. Enter your guesses.
5. Follow the instructions displayed in the console.
